# Desktop shell design direction

`socialspeak-shell-concept.png` is the reference composition for the scaffold.

- Graphite surfaces (`#0d1116` through `#1b222b`) with hairline separators.
- Coral (`#ff5b55`) is reserved for identity, selection, and primary actions.
- Compact system type, 14px base, with restrained 18px section headings.
- Desktop layout: 72px server rail, 248px channels, flexible conversation,
  208px members, and an optional 340px debug drawer.
- The member list drops below 1100px. The debug drawer becomes an overlay
  below 880px. The core rail and conversation remain available throughout.
- The generated concept used a generic transport label; product copy uses QUIC.

The concept is a generated design reference, not a screenshot or evidence of
implemented chat features. Preview participants and messages are sample data.
