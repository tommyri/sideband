# Sideband naming and logo exploration

Offset bands (concept 01) was selected for the Sideband working identity on
2026-11-03. The user chose to proceed with this name and defer domain decisions.
These original exploration boards were generated with the built-in image
generation tool; the production vector master is in `../../public/brand/`.
Internal package names and the existing application identifier remain stable.

## Name check — 2026-11-03

The initial research found direct category overlap with an existing messaging
and telephony app. This finding remains recorded; it does not change the selected
working name. No domain work is planned.

## Concepts

1. [**Offset bands**](01-offset-bands.png): two rounded bent bands suggest an S around a diagonal gap.
2. [**Open channel**](02-open-channel.png): opposing staggered brackets suggest a shared conversation.
3. [**Shared frequency**](03-shared-frequency.png): paired wave ribbons move together through a simple bend.

These are raster concept boards, not final vector masters or production icons.
The symbols can inform another name if the naming direction changes.

## Generation prompts

Shared prompt:

> Use case: logo-brand. Create a polished original logo concept presentation for a proposed friends voice-chat desktop app named Sideband. This is a design exploration, not the existing Reticulum Sideband product; do not copy any existing logo. Square canvas, warm off-white background, charcoal typography, vivid teal symbol. Flat vector-like shapes, exceptional optical balance, generous whitespace, no gradients, shadows, 3D, microphones, headphones or mockup objects. Large symbol centered in upper half, exact wordmark "Sideband" below in carefully spaced contemporary humanist sans-serif. Bottom area contains small monochrome black symbol and a small charcoal rounded-square app icon with off-white version of same mark, aligned neatly. Minimal refined editorial presentation.

Variant 1:

> Concept 01: OFFSET BANDS. Exactly two thick separate rounded bent bands offset diagonally to suggest an S with a clean diagonal negative-space channel. Compact decisive silhouette, understated technical feel. Avoid chain-link infinity shape. Small caption at bottom "01 / Offset bands".

Variant 2:

> Concept 02: OPEN CHANNEL. Two opposing rounded speech-like brackets facing a shared central gap, staggered vertically, conveying two friends in conversation. Construct a compact original emblem with distinct negative space; friendly, open, geometric, not a literal pair of generic speech bubbles. No S monogram required. Small caption at bottom "02 / Open channel".

Variant 3:

> Concept 03: SHARED FREQUENCY. Two parallel soft angular wave ribbons moving together through one clean rising and falling bend; compact horizontal symbol suggesting shared audio frequency and companionship. Bold filled bands, few bends, strong legibility at tiny sizes, clearly different from a letter S, not a busy equalizer. Small caption at bottom "03 / Shared frequency".
